# Demonstration evidence

No demonstration video, GIF, or screenshot is committed at present. This is deliberate: a placeholder would not establish that the Bluetooth keyboard path works on a real host.

To add valid evidence, record one continuous clip showing the following, with sensitive details removed:

1. `python cli.py check` succeeds on the recorded machine.
2. AirKeys starts and the receiving device discovers/pairs with it.
3. Typing into a visible text field on the receiving device, including lowercase, uppercase, shifted punctuation, and Backspace.
4. F12 mute/unmute and a clean stop.

Store the media in a durable release asset or repository location, then add its filename, date, hardware/OS details, and exact tested behavior here. A successful discovery or pairing screen by itself is insufficient evidence.
